# Freelancer Workspace

A pnpm/Turborepo workspace with a Next.js web app, authenticated documentation, Fastify Process API and Storybook. Opportunities follows the reference exports in `.stitch/designs/`; future modules remain disabled.

## Run locally

Use Node 22 and pnpm 10.12.1. Run `pnpm install`. Create ignored `.env.local` from `.env.example` with the restricted Maps/Places keys and the public Firebase Web SDK key. Authorize local Admin SDK access with `gcloud auth application-default login --project=freela-c8c75`. The configured checkout already has these credentials locally; no secrets are committed. Run these in separate terminals:

```sh
pnpm --filter @apps/api dev
pnpm --filter @apps/web dev
pnpm --filter @apps/docs dev
pnpm --filter @apps/storybook dev
```

- Web: http://localhost:3000
- Process API: http://localhost:3011/health and http://localhost:3011/docs
- Documentation: http://localhost:3002 and http://localhost:3002/changelog
- Storybook: http://localhost:6006

Use **Sign in with Google**. Development and production defaults now select Firebase Authentication, Firestore, Google Places and Google Maps. Contact history and pending site requests persist in Firestore per authenticated user. No fictional companies or local sign-in appear in the normal app. The browser talks only to the Next.js Experience API; the Process API independently verifies its Firebase session.

## Live integrations

Google sign-in, local authorized domains, restricted Places/Maps keys and Application Default Credentials are configured and verified for `freela-c8c75`. Live sign-in/session creation, map loading, Places eligibility filtering, and Firestore read/write access have been checked. This is a local frontend/API using real cloud services; a public production deployment is still pending. See [live services](docs/live-services.md) and `deploy/SETUP.md`.

Nearby Search is non-exhaustive and limited to 20 ranked places per query. The app filters out records with a website URL listed. Unknown WhatsApp/Instagram remain unknown. Opening WhatsApp never changes contact status; “Record contact” is a separate versioned, idempotent command. Contact proposals default to English independently of the workspace language. Portfolio URLs are optional; an existing preview URL selects a different proposal. Eight international district presets move the map before an explicit search. Website creation requests can be saved as pending, without an AI generator. See [international prospecting](docs/international-prospecting.md).

## Validate

```sh
pnpm changelog
pnpm lint
pnpm typecheck
pnpm coverage
pnpm test:e2e
pnpm test:stories
pnpm ci:emulators
pnpm ci:coverage-new
pnpm build
```

Content is in `apps/docs/content/en/` and `pt-BR/`, behind the CMS port. Tokens live in `packages/config-tailwind`; accessible components live in `packages/design-system`. See `CONSTITUTION.md` for architecture boundaries.

The emulator suite requires Java 21. `pnpm ci:emulators` uses the ignored local tool download when present, otherwise Java on PATH. Production build outputs and coverage reports are ignored by Git.

Automated tests explicitly use `APP_ENV=test`, fictional fixtures and emulator/mocked services. Playwright owns separate web/API/docs ports 3100/3111/3102 and `.next-test` build directories, so it cannot reuse the live app or spend Places quota. Its local session secret is an inert test fixture. `next-env.d.ts` is generated by Next.js and ignored.
